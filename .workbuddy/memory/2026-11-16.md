## 经典版 / 重制版彻底独立：一条线一个窗口，可同时运行
- 启动页去掉「当前版本」标签与 `is-running` 高亮（`src/ui/home.ts`、`src/style.css` 删除 `home-edition-tag` / `.is-running`）。
- 启动器不再自己进入游戏：每行「启动游戏」开一个该线的窗口。主进程新增 `ow3:open-game`（`electron/main.mjs`），URL 为 `<page>?flavor=<line>&play=1`；`createWindow(url, { flavor, game })`，`game:true` 全屏。
- 主进程新增 `windowFlavors`（webContents.id → line）+ `flavorOf(sender)`：`flavor-get/set`、`install-get/pick/forget/download`、`customkeys-save`、`map-*` 全部按窗口解析，两个窗口各读各的安装；`ow3-install://<sd|hd>/…` 的 host 决定 `serveInstall` 的根（旧页面的 `local` host 回退到启动线）。
- 渲染层：`PickedInstall` 侧的 `installHost()` 用 `flavor()` 当 scheme host；新增 `openGameWindow()`（nativeInstall.ts）与 preload `openGame`。
- 页面语义：`?play=1` = 游戏页，native 自动加载（`startInThisPage`），浏览器需点一次（目录授权要手势）；`?play=1` 页面里的「启动游戏」在本页启动，不再开新窗口（防套娃）。
- 浏览器版：按钮 `window.open(?flavor=..&play=1)`，新标签里再点一次授权；被拦截时提示 `home.popupBlocked`。
- 启动器窗口改为窗口化（不再全屏）、关闭不再等 relay 告别（`createWindow` 里 `if (!game || closeAsked) return`）；`second-instance` 聚焦启动器窗口（`launcherWin`）。
- 新文案：`home.launchedWindow` / `home.launchedTab` / `home.popupBlocked` / `home.playHere` / `home.launchUnsupported`（中英），删 `home.lineRunning`。
- 文档：`SD-HD双版本方案.md` §1/§2.1、`SD-HD开发进度.md` 验收条改为「双线启动」。
- 验证：Electron（`--no-sandbox --disable-gpu --in-process-gpu`，本机 GPU 受限时可用）实测启动器 flavor=sd、`installPath('sd')=…rrrr/Warcraft III`、`installPath('hd')=null`；`openGame('hd')` 返回 true 并开出 `?flavor=hd&play=1` 窗口，该窗口 `flavor.get()=hd`、`installPath()=null` —— 证明按窗口独立。浏览器版实测两行各开一个标签。`tsc`、`cycles`、`app:test` 全过。

## 启动改为进入「加载进度页」（复用 ?dev 的 boot splash），并修好 3.0 安装的 416
- `src/dev/bootSplash.ts` 移到 `src/ui/bootSplash.ts`（不再是 dev-only）：新增模块级单例 + `progressBootSplash()` / `dismissBootSplash()`；logo 与背景按 `import.meta.env.BASE_URL` 拼（网站部署在 `/play/` 下）。`main.ts` 改为静态引用，`?dev` 启动仍用它。
- 启动器（`src/ui/home.ts`）按下「启动游戏」后不再用 hero 里的小进度条，改为全屏进度页：`openSplash()` 把 `loadProfile` 的分档进度喂给它，`main.ts` 的 `showMenu` 在菜单立起来时关闭（改为 `finally`，菜单构建失败也不会永远卡在 100%）。
  - 中文界面下阶段文案用 `boot.mounting`（loader 自带的提示是英文日志）。
- 浏览器版：`window.open("", "_blank")` 先开标签（保住手势，避免 picker 之后被弹窗拦截），然后在**启动器**里选目录（`ensureBrowserFolder`），再 `tab.location.replace(?flavor=..&play=1)`；新标签用 IndexedDB 里的句柄 `queryPermission` 通过就直接进进度页，不再要求第二次点击。取消选目录会关掉空标签并提示。
- **3.0 安装挂载 416 修复**：`Data\ecache` 是外部下载缓存（`data.NNN` 是残缺占位），旧代码遍历整个 `Data` 且 `readdir` 顺序让 ecache 覆盖了 `Data\data` 的真档案 → 越界读返回 416，重制版直接加载失败。`electron/install.mjs` 与 `src/assets/opfs.ts` 的 `collectCasc` 改为只读 `Data\data`（含 .idx）和 `Data\config`，与 `tools/vite-plugin-dev-install.ts` 一致。
- 实测（Electron + CDP）：点重制版「启动游戏」→ 新窗口 1 秒内出现进度页（中文「正在挂载游戏数据…」），进度 2%→8.7%→15.1%…→挂载完成 `vfs=true`，进度页自动消失。`tsc`、`pnpm cycles`、`pnpm app:test` 全过。
